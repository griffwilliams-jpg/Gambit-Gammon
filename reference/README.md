## Current rules and history

The JSON and PDF above are unchanged historical uploads. Their wording may differ from later agreed decisions; do not edit them into a new ruleset.

[Current rules](../docs/rules.md) now use v0.4's Dinar-funded Bazaar. [Agreed decisions](../docs/agreed-decisions.md) records the promotion and retained v0.3 clarifications. [The frozen v0.3 repository](https://github.com/griffwilliams-jpg/Gambit-Gammon/tree/a67d4902b2424491bb556ec60a8089651f88f16c) remains in Git history for control design and comparison.

Earlier draft documentation lacked some recovered design details. Those drafts are historical and must not be treated as evidence that the current recorded decisions are still unapproved. Outstanding Bazaar rules and balance questions are listed explicitly in [open decisions](../docs/open-decisions.md).
